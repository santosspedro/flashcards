# Atlas Prático

Flashcards visuais para estudo da Avaliação Teórica e Prática 1 de Ciências Morfofisiológicas: sistemas tegumentar, articular, ósseo e muscular.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie os arquivos desta pasta para a raiz.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione a branch `main`, pasta `/ (root)` e salve.

O site é estático e não requer instalação ou compilação.
