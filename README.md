# Atlas Prático

Revisão de morfofisiologia para enfermagem com quatro temas: sistema digestório, coração, vasos sanguíneos e sistema linfático.

Abra `index.html` no navegador. O site é estático e funciona sem instalação. Para consultar as fotos legendadas dos modelos anatômicos em **Prática**, é necessário acesso aos arquivos originais.

- **Resumos** reúne os pontos de cada tema e perguntas para explicar em voz alta.
- **Flashcards** permite revelar uma resposta e marcar os cartões que precisam de revisão.
- **Quiz** apresenta alternativas e explica o gabarito a cada resposta.
- **Prática** traz exercícios com esquemas anatômicos sem rótulos, um marcador e campos para responder o nome e a função. As fotos legendadas de referência estão vinculadas nos exercícios do sistema digestório.
- **Revisar erros** reúne questões erradas e cartões marcados para rever. A lista é salva no navegador.

Para usar no GitHub Pages, selecione a branch e a raiz do repositório em **Settings → Pages**.
